# Drag'n'Wash Slap Jump Mod

Slap things so hard you can launch yourself off from them! Our kobold went to the gym, letting it do a rocket-jump style super slap!

# Installation

Simply download the [latest version of the DnW Mod Manager](https://github.com/KrazenLabs/dnw-modmanager/releases/latest), which will let you install the mod directly. No separate download needed!

# Usage

Slap things and go flying! The F10 menu contains some options to let you tweak how ridiculous you want to make things :)

# How to uninstall

Just remove it using the Mod Manager.
